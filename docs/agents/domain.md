# Domain Docs

## Layout

Repo ini single-context: istilah domain di `GLOSSARY.md`, keputusan arsitektur di `docs/adr/`.

## Consumer rules

- Sebelum mengeksplorasi kode, baca `GLOSSARY.md` dan ADR yang relevan di `docs/adr/`.
- Jika dokumen tersebut belum ada, lanjutkan tanpa meminta pembuatannya. Buat dokumen secara bertahap saat istilah atau keputusan benar-benar disepakati melalui domain-modeling.
- Gunakan istilah glosarium pada judul issue, spec, proposal, dan nama pengujian. Hindari sinonim yang dilarang glosarium.
- Jika usulan bertentangan dengan ADR yang ada, sebutkan konflik secara eksplisit.
- Jika di masa depan tersedia `GLOSSARY-MAP.md`, ikuti peta tersebut untuk membaca glosarium dan ADR konteks yang relevan.
