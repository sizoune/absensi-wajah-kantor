# Triage Labels

| Canonical role | Label di GitHub | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer perlu mengevaluasi issue |
| `needs-info` | `needs-info` | Menunggu informasi tambahan |
| `ready-for-agent` | `ready-for-agent` | Spec lengkap, siap dikerjakan agent |
| `ready-for-human` | `ready-for-human` | Memerlukan implementasi manusia |
| `wontfix` | `wontfix` | Tidak akan dikerjakan |

Gunakan label di atas ketika skill menyebut peran triage terkait. Pertahankan label proyek lain yang sudah ada.
